# Verified staged restore

Construct `Restore` with its `Store`, simulator `Drive`, host-configured restore `Roots`, private `Spool`, free-space `ReserveBytes`, and optional read-only `LegacyRoots`. `Preview(ctx, Options)` reads the catalog without device access. `Execute(ctx, store.Job)` accepts a claimed RESTORE job and leaves unsuccessful terminalization to the scheduler.

Options select one archive, either all members or stable member IDs, an allowlisted restore root ID and a fresh destination slug. Legacy restoration additionally requires the recorded source ID, explicit `simulator-plain-tar-v1` profile and operator confirmation. Legacy integrity remains OBSERVED after restore.

The complete archive graph is checked before selecting output. Directory selections expand descendants and recorded parent directories. Hardlink selections include their complete earlier-target chain. Symlink resolution checks the actual link graph and parent traversal, including symlinks combined with `..`. Archive members cannot use symlinks as ancestors. Duplicates, unsafe effective PAX names, special files, cycles, missing hardlink targets and unsupported TAR semantics fail closed.

Preview supports at most one million members, 64 MiB of aggregate raw/canonical/parent/link text, 128 path components and 10,000 requested IDs. It returns at most 200 representative members plus expansion counts. These bounds are checked while fetching rows. The selected and complete graph remain bounded in memory. Hardlink chains are limited to 128 and symlink resolution to 40 expansions.

Execution checks managed UUID and immutable header digest under a retained lease, or reidentifies the pinned legacy source. The entire logical archive is read into an exclusive 0600 spool in a private 0700 directory. Free space is checked for spool, logical output and reserve, accounting for shared filesystems. EOM, corruption, short files, disk errors, failed close, bad framing or catalog/header disagreement prevent extraction. The spool is synced, closed, reopened and scanned against the complete catalog graph before its verification evidence is stored.

GNU tar runs as the unprivileged application user using fixed arguments, pinned directory/file descriptors and a literal NUL-delimited selection. Extraction restores no ownership, ACLs, xattrs or SELinux metadata. Postwalk checks exact allowed entries, types, regular sizes, symlink values and hardlink inode identity. It strips privileged mode bits, preserves ordinary permission bits and syncs files/directories. The private staging root retains mode 0700. A Linux no-replace rename publishes the tree on the destination filesystem after a durable publication intent. Completion is recorded atomically in SQLite. A crash or database failure after rename requires inspection of the recorded root and slug, without replay or automatic deletion.

Failures remove only this invocation's unpublished private stage and spool through pinned roots. A tree already published remains available for investigation. Restore refuses root execution. The source roots and restore root owners must remain trusted. Free-space estimates cannot reserve filesystem capacity against other host processes, so extraction errors still fail safely.

The generated PAX integration corpus exercises effective path and size overrides through actual legacy import, spool validation and GNU extraction. Safe effective fields are restored literally. Absolute/traversing overrides, negative sizes and oversized extended headers produce no output and preserve an external sentinel.
